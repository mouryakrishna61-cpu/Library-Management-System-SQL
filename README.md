# Library Management System Analysis using SQL

## 1. Project Overview
This project focuses on analyzing a Library Management System using SQL. The objective is to understand book records, student borrowing activity, pending returns, and fine collection.

## 2. Project Objectives
- Analyze book availability by category.
- Identify the most issued books.
- Track student borrowing activities.
- Identify pending book returns.
- Calculate total fine collection.
- Analyze unpaid fines.
- Identify the most active students.
- Analyze department-wise borrowing activity.

## 3. Database Structure
The project consists of four tables:

1. **Students** – Student ID, name, department, class and phone number.
2. **Books** – Book ID, book name, author, category and price.
3. **Issue Books** – Student ID, book ID, issue date, return date and status.
4. **Fine** – Fine details, amount and payment status.

## 4. SQL Analysis – Key Questions

The project covers 14 SQL questions:

1. Total books by category.
2. Most issued books.
3. Students who borrowed books.
4. Pending book returns.
5. Total fine collected.
6. Students with unpaid fines.
7. Top 5 active students.
8. Department-wise book issue count.
9. Books not issued yet.
10. Monthly book issue report.
11. Total returned and pending books.
12. Students who issued more than one book.
13. Book issue details with student and book names.
14. Total fine amount by payment status.

## 5. Key Business Insights
- Identify popular book categories.
- Understand student borrowing patterns.
- Monitor pending book returns.
- Track fine collection and unpaid amounts.
- Identify active students and departments.
- Understand monthly library usage.
